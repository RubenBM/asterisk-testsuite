# Security Policy

This repository is a personal downstream fork of the official
[Asterisk Test Suite](https://github.com/asterisk/testsuite).

The security policy and reporting process below are inherited from the
upstream Asterisk Test Suite project.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in the Asterisk
Test Suite, please report it privately through the security reporting
mechanism provided by the upstream Asterisk project.

**Do not report security vulnerabilities through public GitHub issues.**

Please see the upstream security policy for the current reporting procedure:

https://github.com/asterisk/testsuite/security/policy

The upstream Asterisk project is responsible for the official security
response and disclosure process.

## Scope

This fork currently contains no intentional downstream security
modifications.

If this repository later diverges from upstream in a way that introduces
security-relevant changes, its security documentation may be updated at
that time.
