# Security Policy

This repository is a personal downstream fork of the official
[Asterisk Test Suite](https://github.com/asterisk/testsuite).

## Reporting a Vulnerability

If you discover a security vulnerability that is specific to changes
introduced in this fork, please report it privately through the security
reporting mechanism provided by GitHub for this repository.

Do not disclose security vulnerabilities through public issues.

For vulnerabilities affecting the upstream Asterisk Test Suite itself,
please follow the security reporting process documented by the official
Asterisk project:

https://github.com/asterisk/testsuite/security/policy

This repository is not an official Asterisk project repository and does
not replace the upstream project's security reporting process.
